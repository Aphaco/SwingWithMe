# SWING WITH ME EVENTS — React + Vite

A custom first milestone for a soft-pink luxury event planning website. The hero includes an interactive Three.js / React Three Fiber sculpture, with GSAP-powered entrance and scroll reveals. The rest of the page establishes the alternating deep-plum and warm-ivory visual system.

## Requirements
- Node.js 18+ (Node.js 20+ recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints in your terminal.

## Production build

```bash
npm run build
npm run preview
```

## First milestone features
- Custom hero composition with interactive 3D sculptural bloom
- Responsive mobile navigation
- Pink / ivory / deep plum design system
- GSAP hero and scroll reveal motion
- Services, brand philosophy, gallery, and contact CTA sections
- Reduced-motion preference support

## Before launch
- Replace the placeholder Unsplash images with the agency's own event portfolio.
- Update the contact email and social links.
- Confirm service categories and copy with the client.
- Add a real enquiry form and connect it to an email or CRM service.
- Test the site on target mobile devices and run `npm run build`.

Images and Google Fonts currently load from external services and require an internet connection.
